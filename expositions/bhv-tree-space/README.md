# Brownian Motion in BHV Tree Space

These notes discuss Brownian motion, bridges, and Bayesian inference in
Billera–Holmes–Vogtmann phylogenetic tree space. The source is in `main.tex`,
with shared commands in `preamble.tex`, citations in `references.bib`, and
figures in `images/`.

From the repository root, rebuild the PDF with:

```bash
make expositions
```
